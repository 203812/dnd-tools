About this map

This is a single-screen map: perfect for a laptop at the table or for sharing your screen over a call, but it is not a shared virtual tabletop. There is no server behind it, so players cannot join from their own devices and move their own tokens. Everything you place is stored in this browser and can be exported as a file to carry between machines.
